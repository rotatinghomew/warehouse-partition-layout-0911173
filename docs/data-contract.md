# 表布局与查询含义

occurred代表绝对事件时间，region允许空值，event_id是稳定业务键。旧版utc_day来源于UTC日历，不是活动地区业务日。地区业务时区登记在regions.json，不能从地区名称或机器本地时区推断；空地区没有已知地区业务日。

新版写入约定可包含地区与业务日，布局变化不改变事件时间。历史表版本代表固定的业务记录与文件集合。物理目录名称不能单独证明文件内容范围，表清单中的规格身份与统计才有可验证含义。迁移复制出的文件只有成为有效清单一部分才参与读取。

筛选语义为绝对时间半开区间，regions=None表示不限制地区，regions列表里的None表示包含空地区，空列表表示不返回任何地区。selected和skipped用于解释实际候选文件选择，不是提前承诺查询一定返回行。
